# Sprint NN report template

**Sprint** · Number and milestone  
**GSD reference** · Phase  
**Target release** · Version  
**Status** · Open, blocked, or closed  
**Date** · Update or closeout date

## Outcome and story status

Record each phase and story ID, what shipped, the status, and the commit or artifact that supports it. During an open sprint, list pending work and the next exit condition.

## Verification

Record each applicable check, its result and where the evidence lives. Include Gradle and platform builds, Graphify and OpenCodeReview when required. Identify the host, device or simulation, app build, and test conditions. Mark checks without evidence as pending or unverified.

## Closeout and follow-up

Link integration and release evidence when available. Record any field checks, limitations, or approved follow-ups. Link the canonical work from the repo report index and from the Intercom-Alpha hub or Kanban in Obsidian.
