The current-state pages reflect Sprint 37 at commit `57b55de`. **Present in source** means the cited code or route exists. **Runtime check needed** identifies missing device evidence. **Gap** marks an observed disconnect. **Proposed** marks future design or roadmap work. The atlas does not record a fresh device test.

For the public introduction, open [the static page](../index.html) locally. To publish later, use GitHub Pages with the approved branch and its `/docs` folder as the source. The page uses relative links for its stylesheet and system map.
